# 読み手の規範

文書の種類(仕様書・手順書・レポート・議事録など)ごとの形式は、本スキルでは定めない。その時々にユーザーと決める。本ファイルが定めるのは、形式を決める前提となる読み手の分類だけである。

## 1. 分類

- **本人向け**: 書き手(ユーザー)自身が読む文書。読み手は文脈を知っており、必要な知識も一通り持つ。
- **他者向け**: ユーザー以外が読む文書。読み手は文脈を知らず、持つ知識も様々である。
- どちらに当たるかをユーザーに確認してから書き始める。

## 2. 本人向け

- 前提・経緯・用語の定義を省いてよい。
- 作業ツリー内のパスや中間ファイルを参照してよい。
- 結論と根拠だけを書く。

## 3. 他者向け

- 結論の前に、対象・経緯・用語の意味を置く(`paragraph.md` 3.)。
- 作業フォルダ内のパス・中間ファイルを参照しない(`format.md` 4.)。
- 検討の途中経過や内部的な分析を残さない。
- 読み手が持たない知識を前提にせず、必要なら本文で説明する。
- 確信度のラベル(`sentence.md` 4.)を必ず使う。

## 4. 文書の形式

- 見出し構成・必須要素・雛形はスキルで定めない。読み手の分類と文書の目的から候補を提案し、ユーザーと合意して決める。
