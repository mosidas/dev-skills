# 議事録の型

## 1. この型が答える問い

議事録が答える問いは「何が決まり、誰が、いつまでに、何をやるか」である。発言録ではない。読み手の大半は会議に出ていなかった人か、記憶があいまいな人であり、数十秒で決定事項と宿題を確認できれば用が足りる。発言を時系列でなぞった記録は、決定事項を本文に埋没させ、読み手にもう一度全文を読ませる。

## 2. 必須要素

- 会議名・日時・参加者。
- 記録の前提の開示(冒頭に一段落): 録音の有無、文字起こしの精度、話者識別の確信度、訂正の連絡手段。あとの本文をどこまで信じてよいかを読み手が判断できるようにする。
- 議題ごとの議論の要点。
- 決定事項・宿題(担当者と期日つき)・継続議題。この 3 つは本文の議論から独立させ、末尾か冒頭に集約する。
- 宿題は担当者・期日・内容の 3 点セットとする。「チーム全員で対応」「なるべく早く」は担当と期限の放棄であり、この型では使わない。担当者が未定なら「未定(次回までに決める)」と正直に書く。

## 3. 構成の型

- 冒頭に会議メタ情報と記録の前提、本文は議題ごとに節を切り、末尾に決定事項・宿題・継続議題をまとめる。必要なら「次回に向けたメモ」を、本文の再掲でなく次回何を変えるかの差分だけで添える。
- 議題見出しは、その議題で何が起きたか(何が決まったか)を一言で表す。見出しレベルは議題の粒度に合わせ、2 行で済む議題を 10 行の議題と同格にしない。
- 議論の経緯や意見の応酬は因果と時系列があるため地の文で書き、箇条書きは決定事項・宿題のように真に並列な項目だけに使う。助言の一覧のように後から特定の項目を探す走査性に価値があるものは、地の文へ均さず箇条書きのまま残す。
- 「引き続き検討する」は決定ではなく先送りなので、継続議題の欄に回す。

## 4. 品質基準

- 決定は本文を読まなくても末尾の一覧だけで分かる。
- 宿題は「田中: 回転率ベースのしきい値案を 7/18 までに作成」のように読める(担当・期日・内容)。
- 発言の確信度が書き分けられている。話者を推定した箇所は「(佐藤さんと推定)」のように注記する。
- 助言・指摘には相手の反応が最低一言(「了承した」「持ち帰って検討する」)添えられ、一方向の講義録になっていない。
- リライトで原文にない列・節(期日列・継続議題)を足した結果、「未定」「継続実施」ばかりで埋まるなら、その列・節は足さない。形だけの網羅は欠落より機械的に見える。

## 5. やりがちな失敗

- 全発言を均等な熱量で要約し、決定事項が他の意見と同じ重みで埋もれる。5 分の確認事項と 30 分の論点を同じ行数で並べない。
- 話者の確信度の平坦化。全員が言い切りになるか、全員が「〜と思われる」になり、自信のある発言とない発言の区別が消える。
- フィラー(「えーと」)は消すのに、話し言葉の冗長な言い回しを残す。「その件についてはですね、まあ一旦持ち帰らせていただいて〜」は「持ち帰って検討する」で済む。

## 6. 共通規範への例外と重み付け

- 例外: 文体は体言止めと「である」調の記録調を許容する(`format.md` 3. の「体言止めを避ける」の例外)。
- 例外: 核心発言は発言者の口調のまま残し、整形の対象外とする(「測ってるからやって」を「測っているからやってほしい」に直すと、生々しさと出典性が消える)。
- 例外: 議題見出しは決定内容を言い切ってよい(`format.md` 2. の「セリフにしない」の例外)。
- 重み付け: 確信度の明示(`sentence.md` 6.)と濃淡(`composition.md` 4.6)を特に強く適用する。

## 7. 雛形

```
# 在庫すいすい開発定例(2026-07-10)

出席: 田中(PM)、佐藤(バックエンド)、鈴木(デザイン)
記録: 会議の録音はなく、田中のメモをもとに構成した。発言者の帰属は
おおむね確実だが、一部推定が入る箇所は「(推定)」と注記する。訂正
はこのドキュメントへのコメントで受け付ける。

## 在庫アラートのしきい値は在庫数でなく在庫回転率で決める
現行のしきい値(在庫数10個未満で通知)は季節商品で誤検知が多いと
佐藤が指摘した。鈴木は、店舗担当者からも同様の苦情が来ていると
補足した(推定: どの店舗からかは未確認)。在庫回転率を基準にする
案を田中が提案し、大筋で合意した。

## 決定事項
- しきい値の算出方法を在庫数から在庫回転率に変更する

## 宿題
- 田中: 回転率ベースのしきい値案を7/18までに作成
- 佐藤: 現行ロジックの改修範囲を7/15までに見積もる

## 継続議題
- 通知先をSlackに一本化するかは未定。次回、鈴木がUI観点の意見を持ち寄る
```
