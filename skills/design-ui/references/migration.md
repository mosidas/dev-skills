# 見た目の移行

本書は見た目を変えずに UI の実装を置き換える移行の工程を定める。置き換えの例はスタイルの仕組みの入れ替えとコンポーネントライブラリの入れ替えである。見た目の一致は目視でなく画像差分で確かめる。目視は数画素の差を見落とすためである。

## 1. 適用範囲

- 対象は見た目を変えずに実装を置き換える移行である。見た目を変える変更(リデザイン・配色と間隔の変更)は対象外とする。
- 本書の移行は develop の `../../develop/references/kinds.md` 6. の移行の種類に当たる。kinds.md 6. の旧版の出力は 2. の基準の撮影と読む。出力の一致は画像差分 0 と読む。

## 2. 基準

- 移行を始める前に現在の実装のコンポーネントを状態ごとに撮影して基準とする。状態は `checklist.md` 2. の状態のうち該当するものである。2 つの実装の見た目を合わせるときは移行先も同じ状態で撮影する。
- 撮影には draw-diagram の `render.py` の `screenshot()` を使う。使い方は `session.md` 3.4 に従う。撮影に使う HTML・コマンド・幅・高さは基準と比較で同じにする。
- 基準は移行の後でなく前に作る。計画のステップ 1 を基準の撮影にする。基準の画像と撮影に使う HTML はステップ 1 でコミットする。撮影と比較のコマンドは計画に書く。各ステップで同じコマンドを使う。
- 基準の無いまま一致を主張しない。
- 基準の見た目がおかしいとき(崩れ・はみ出し・誤った状態)は基準を直さない。止めて本人に聞く。基準を直すと比べる相手が移行の前の見た目でなくなるためである。

## 3. 禁じること

- 次の 3 つを禁じる。
  - 撮影の仕組み(撮影に使う HTML・コマンド・幅・高さ)の変更。
  - 基準の画像の変更と撮り直し。
  - 差分を 0 にするためのコンポーネントの構造の変更(要素の削除・入れ替え・非表示の指定)。
- 3 つは `agents/gate-reviewer.md` の進め方 2 の検査の変更と同じ扱いとする。検査を緩める変更と同じく見た目の差を見逃すためである。

## 4. 進め方

- 共有の部品(トークン・基本のコンポーネント)を先に移す。共有の部品の移行を終えるまで個々のコンポーネントに進まない。共有の部品の差はそれを使うすべてのコンポーネントの差に現れるためである。
- 個々のコンポーネントは 1 つずつ移す。
- 1 つを移したら 2. と同じ方法で撮影して基準と画像差分で比べる。差分が 0 でなければ不合格とする。差の出た画素の箇所を調べて新版を直す。目視で合格にしない。
- 1 つのコンポーネントか安全な束(互いに依存せず差分がすべて 0 のコンポーネントの組)ごとに PR にする。
- 複数のコンポーネントを並列に移すときは develop の `../../develop/references/parallel.md` 2. の書き込み先の分離に従う。1 つのコンポーネントに 1 人の作業者を当てる。

画像差分には既存の道具を使う。新しいスクリプトは作らない。候補は次の 2 つである。`which compare` と `python3 -c "import PIL"` で確かめて環境にある方を使う。どちらも無いときは止めて本人に聞く。

- ImageMagick: `compare -metric AE <基準>.png <新版>.png <差の画像>.png` で比べる。標準エラー出力に差の画素数を出す。0 が合格である。ImageMagick 7 では `magick compare` とする。
- Python の Pillow: 次のコマンドで比べる。差があれば差の範囲(左・上・右・下)を出して終了コード 1 で終わる。差が無ければ `None` を出して終了コード 0 で終わる。

```sh
python3 -c 'import sys; from PIL import Image, ImageChops; a, b = (Image.open(p).convert("RGB") for p in sys.argv[1:3]); d = "大きさが違う" if a.size != b.size else ImageChops.difference(a, b).getbbox(); print(d); sys.exit(d is not None)' <基準>.png <新版>.png
```

## 5. 報告

- 報告には次の 4 つを書く。
  - 移したコンポーネント。
  - コンポーネントごとの画像差分の結果(差の画素数か差の範囲と使った道具)。
  - 基準の置き場(基準の画像と撮影に使う HTML のパス・撮影と比較のコマンド)。
  - 残りのコンポーネント。
