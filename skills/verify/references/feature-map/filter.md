# タスクの絞り込み

絞り込みでは利用者が題の語でタスクを探して該当したタスクを開く。完了済みのタスクは既定で対象の外である。該当なしの状態と絞り込みを解除した状態は画面で見分けられる。

## サブ機能

- `filter-open`: ブラウザーの各入口から絞り込みを開く。
- `filter-match`: 題に語を含むタスクを返す。タスクのデータは変えない。
- `filter-done`: `完了済みを含める` に印を付けると完了済みのタスクも返す。
- `filter-open-result`: 結果のタスクを詳細の画面で開く。
- `filter-empty`: 該当が無い語に該当なしの状態を出す。
- `filter-clear`: 語を外して最近のタスクの表示に戻す。
- `filter-cli`: 端末から同じタスクを返す。

## 利用者からの到達

- ブラウザーのツールバーの `絞り込み` ボタンを押す。
- 入力欄の外にフォーカスがある状態でブラウザーで `/` を押す。
- 端末で `tasks list --query <語>` を実行する。

## 操作

前提:

- Tasks が `http://127.0.0.1:5173` で健康診断を通っている。
- 使い捨てのデータのディレクトリに未完了の `週次の報告` と完了済みの `請求書の送付` がある。
- `drive doctor` が期待する URL とデータのディレクトリを示す。

- **ツールバーから開く**: `絞り込み` ボタンを押す。`drive browser click --role button --name "絞り込み"` を実行する。`タスクの絞り込み` という名前のダイアログが現れる。検索欄にフォーカスがある。
- **キーボードから開く**: ダイアログを閉じてページにフォーカスを戻してから `/` を押す。`drive browser press --key "/"` を実行する。同じダイアログが現れる。ページに `/` は入力されない。
- **題で絞り込む**: `週次` と入力する。`drive browser fill --role searchbox --name "タスクの絞り込み" --value "週次"` を実行する。`絞り込みの結果` の一覧に `週次の報告` がある。`請求書の送付` は無い。
- **完了済みを含める**: 語を `請求書` に替える。`drive browser fill --role searchbox --name "タスクの絞り込み" --value "請求書"` を実行する。`該当するタスクはありません` という名前のステータスが現れる。続けて `drive browser check --role checkbox --name "完了済みを含める"` を実行する。一覧に `請求書の送付` が現れる。
- **結果を開く**: `週次` で絞り込み直して `週次の報告` を押す。`drive browser click --role link --name "週次の報告"` を実行する。ダイアログが閉じる。詳細の画面の見出しが `週次の報告` である。
- **該当なし**: 絞り込みを開き直して `火山` と入力する。`drive browser fill --role searchbox --name "タスクの絞り込み" --value "火山"` を実行する。絞り込みが終わった後に `該当するタスクはありません` という名前のステータスが現れる。
- **解除する**: `絞り込みを解除` を押す。`drive browser click --role button --name "絞り込みを解除"` を実行する。検索欄が空になる。結果の一覧の代わりに `最近のタスク` の領域が出る。
- **CLI で一致する**: 端末から絞り込む。`drive cli -- tasks list --query "週次" --format json` を実行する。終了コードが `0` である。標準出力は題が `週次の報告` のオブジェクト 1 つである。
- **CLI で該当なし**: 無い語で絞り込む。`drive cli -- tasks list --query "火山" --format json` を実行する。終了コードが `0` である。標準出力は `[]` である。
- **証拠を取る**: 結果がある状態を撮る。`drive browser snapshot --aria --path "$EVIDENCE_DIR/filter/results.aria.txt"` と `drive browser screenshot --path "$EVIDENCE_DIR/filter/results.png"` を実行する。2 つの証拠に Tasks の名前・語・`週次の報告` が写る。

## 落とし穴

- 入力欄か検索欄にフォーカスがあるときに `/` を押すと文字が入力される。絞り込みは開かない。
- 結果は入力の少し後に更新される。決まった秒数を待たない。結果の一覧か該当なしのステータスが出るのを待つ。
- 完了済みのタスクは `完了済みを含める` に印を付けない限り結果に出ない。
- CLI の既定の出力は人が読む形である。判定には `--format json` を使う。
- 結果を開くとブラウザーの状態が変わる。次の語を確かめる前に絞り込みを開き直す。
