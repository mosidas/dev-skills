# 日本語ライティング規範

本スキルは、日本語の開発ドキュメントや技術文書を書く・推敲する規範を次の束に分け、`references/` に収める。作業に必要なファイルだけを読む。

| 束 | ファイル | 扱う規範 | 読むとき |
| :-- | :-- | :-- | :-- |
| 言語 | `references/sentence.md` | 語の選び方、文の組み立て、動詞と語彙、事実・意見・確信度、翻訳調、表記、記号、出典 | 本文を書く・直すとき |
| 言語 | `references/paragraph.md` | 段落、論証の厳密さ、構成(伝えたいことの 1 文と節の役割の表)、接地と省略、スケルトン通読、削除テスト、見出し | 段落・章節・見出しを書く・点検するとき |
| 読み手と工程 | `references/readers.md` | 読み手の分類(本人向け・他者向け)と、分類ごとに省いてよいもの、確認できないときの事実と推測の書き分け | 書き始める前 |
| 読み手と工程 | `references/process.md` | 工程の一覧、着手時の brief、骨組みの合意、疑問の一覧、肉付けの優先規則、レビュー役に渡す物、指摘を受けた後 | 書き始める前と、工程を進めるとき |
| 読み手と工程 | `references/inspection.md` | 検査スクリプト(`scripts/`。依存はスクリプト内で宣言済みで、`uv run` で実行する)と hooks の使い方、検出への対応、長い文書の推敲の分担、別のエージェントによるレビュー、判断台帳、収束条件 | 書いた後に点検・推敲するとき |
| 形式 | `references/format/markdown.md` | Markdown の見出しの階層、記法(GFM・frontmatter・アラート) | Markdown の文書を書く・直すとき |
| 形式 | `references/format/html.md` | HTML で配布する文書の折りたたみのラベル | HTML の文書を書く・直すとき。スライドは write-slide、HTML で配布する説明資料は write-page から読む |
| 種類 | `references/types/` | 文書の種類ごとの決まり | brief で決めた種類のファイルがあるとき |
