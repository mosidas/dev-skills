# 議事録

本ファイルは、議事録(会議で話したこと・決めたこと・宿題を残す文書)の決まりを定める。

## 1. 読み手

読み手は出席者と欠席者である。欠席者は会議の文脈を持たない。出席者は、決定事項と自分の宿題を確かめるために読む。

## 2. 節の並び

新しく作るときは、冒頭に日時・場所・出席者を書く。続けて、議題、話題ごとの記録、決定事項、宿題、次回の順に置く。決定事項・宿題が無い会議では、その節を作らない。話題は会議で出た順に並べる。宿題には担当と期限を書く。決定事項と宿題は並列の項目として箇条書きにしてよい(`../paragraph.md` 1.)。

## 3. 足す規則

- 議事録を推敲するときは、話題の順と見出しを変えない。散文の記録を項目に分けるのはよい。話題ごとに並べ替えるのは、会議のメモから新しく作るときに限る。
- 発言を引用するときは、`../sentence.md` 4. の「引用した話し言葉と、改行で区切る書き方は、読解を妨げない限り均さない」に従う。
- 素材に無い担当・期限は作らず、確認できなければ「未確定・要確認」と書く(`../process.md` 4.)。

## 4. 外してよい規則

`../paragraph.md` 3. の「結論から始める」と「『なぜ』が伝えたいことにつながらない節は、節ごと削る」は外す。記録は会議の順に並べ、議題を削らない。

## 5. 検査で見る点

- `lint.py --genre business` で検査する。ファイル名に `minutes` か `議事録` を含むときは、`hooks/inspection.config.json` の doctypes が検査 hook に business を割り当てる。
- 宿題のすべてに、担当と期限か「未確定・要確認」があるか。
- 話題の順が会議の順と一致するか。
