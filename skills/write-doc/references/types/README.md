# 文書の種類

このディレクトリには、文書の種類ごとの参照ファイルが入る。各ファイルは次の 5 節を持つ。

1. 読み手: その種類の文書を読む人と、その人が知っていること・知らないこと。
2. 節の並び: 文書の冒頭から末尾までに置く節とその順序。
3. 足す規則: 共通の規範に加えて、その種類で守る規則。
4. 外してよい規則: 外す規則を `<ファイル> <節>` で名指しし、外す条件を書く。
5. 検査で見る点: 書き終えた文書で、その種類に固有に確かめる点。

| 種類 | ファイル | 扱う文書 | 主な読み手 |
| :-- | :-- | :-- | :-- |
| 手順書 | `procedure.md` | 手順書・マニュアル | 手順を再現する人 |
| 仕様書と規約 | `spec.md` | 仕様書・規約・運用の規則 | 実装者・運用者・レビュー役 |
| 議事録 | `minutes.md` | 議事録 | 出席者と欠席者 |
| 調査レポート | `report.md` | 調査・分析・評価レポート、リサーチメモ | 判断する人 |
| 技術記事 | `article.md` | 技術記事・技術書の章・解説文 | 題材を知らない他者 |
| 企画書と PRD | `proposal.md` | 企画書・PRD(製品要求仕様書) | 承認する人。PRD は build と planner |

表に無い種類は `../process.md` 2. の brief で形式を合意する。
