# README

本ファイルは、リポジトリの README(リポジトリを開いた人が最初に読む文書)の決まりを定める。雛形は `../templates/readme.md` にある。

## 1. 読み手

読み手はリポジトリを初めて開いた人である。使う人と開発に参加する人の 2 種類がいる。使う人は、何をするものかと、入れて動かすまでを知りたい。開発に参加する人は、環境を用意してビルドとテストを動かすまでを知りたい。どちらもコードを読めるが、まだ読んでいない。README はコードを読む前に読む文書であり、コードを読めば分かることを読み手に先回りして伝える文書ではない。利用者のいないリポジトリ(社内のサイト・自分だけが使う道具)では、読み手は開発に参加する人だけである。

## 2. 節の並び

冒頭に題名と、何をするものかの 1 文を書く。導入の節は設けない。画面を持つアプリでは、1 文の直後に画面の画像を 1 枚置いてよい。続けて、動作環境(必要なもの・権限とその用途)、インストール、使い方、開発、ライセンスの順に置く。インストールには配布物の形式を、使い方には最初の流れの後に既定の保存先を書く。使い方は、配布物(ライブラリ・CLI・GUI)ごとに、利用者が最初にする 1 つの流れだけを書く。開発は、環境の用意(道具と版・devcontainer・秘密情報の置き場)、ビルド、テストをそれぞれ 1 つ書く。該当しない節は削る。利用者のいないリポジトリでは、インストールと使い方を削り、開発の節を本体にする。

## 3. 足す規則

- 2. で定めた項目(1 文・画面の画像・動作環境・配布物の形式・既定の保存先・ライセンス)は問わずに書く。それ以外を書くかどうかは 2 つの問いで決める。1 つ目は「それが無いと、読み手は最初の流れ・環境の用意・ビルド・テストを始められないか」である。始められるなら書かない。内部の層、処理の順序、失敗時の内部の挙動、設定ファイルのキーの一覧がこれに当たる。2 つ目は、始められないものについて「README が無くても、慣習で場所が決まったもの(`--help`・画面・依存の宣言・CI の設定・`LICENSE`)から得られるか」である。得られるなら書かない。ディレクトリ構成と技術スタックがこれに当たる。ただし、最初の流れの前に必要な前提(道具と版・devcontainer)は、依存の宣言から得られても 1 行で書く。
- サブコマンド・オプション・エラーコード・キーバインドの全部の一覧は書かない。README には、最初の流れに出てくるものだけを書く。`--help` と画面が持たない一覧(終了コードなど)は、`docs/<名前>.md` にリファレンスとして分け、README からリンク 1 行で参照する。
- 2 つ目以降の流れと場面ごとの手順(他のアプリとの連携・移行・復元)は、`docs/<場面>.md` に手順書(`procedure.md`)として分け、README からリンク 1 行で参照する。
- CI の仕組み、テスト用データの再生成、リリースの手順は `docs/` か `CONTRIBUTING.md` に分ける。配布物を作る手順でも、利用者が入手する手段がそれしかないときは、インストールの節にソースからのビルドとして書く。
- インストールの節は、配布の形(Releases・パッケージマネージャー・ソースからのビルド)ごとに 1 段落か番号付きの手順 1 つで書き、起動の確かめ方で終える。
- 分量は、画面を 2 回送らずに読める量(100 行)を目安にする。超えたら、文を削るのではなく、2. に無い節と 2 つ目以降の流れを別の文書に分ける。

## 4. 外してよい規則

- `../readers.md` 3. と `../paragraph.md` 3. の「結論の前に導入を設け、対象・経緯や用語などの前提・扱う範囲を説明する」は外す。題名の直下の 1 文が導入に当たる。経緯は書かない。
- `../paragraph.md` 1. の「因果と経緯は地の文で書く」と「番号・記号は、後で番号を使って参照するときだけ振る」は、使い方とインストールの操作の順序には適用しない。操作の順序は番号付きの箇条書きにしてよい。

## 5. 検査で見る点

- 見出しが 2. の節の名前だけか。該当する節が欠けていないか。
- 2. で定めた項目以外の各文が、3. の 2 つの問いを通るか。
- 一覧が、最初の流れに出てくるものだけか。`--help` と画面が持たない一覧に、分けた先があるか。
- 使い方の流れが、配布物ごとに 1 つか。
- 開発の節が、環境の用意・ビルド・テストのそれぞれ 1 つ以内か。CI・リリース・テスト用データの再生成が本文に無いか。
- インストールの節が、起動の確かめ方で終わるか。
- 100 行を超えていないか。超えているとき、分ける先の文書が決まっているか。
- リンク先の文書が存在するか。
