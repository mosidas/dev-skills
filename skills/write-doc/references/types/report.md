# 調査レポート

本ファイルは、調査・分析・評価レポート(調べた事実を判断の材料にまとめる文書)の決まりを定める。リサーチメモも本ファイルに従う。

## 1. 読み手

読み手は、レポートを読んで判断する人である。調査の過程は知らない。本人向けのメモは `../readers.md` 2. に従う。

## 2. 節の並び

冒頭に対象と範囲、結果と結論の要約を書く。続けて、方法、項目ごとの結果、結論と次の行動(または選択肢。根拠が無いときと定点観測では結論だけ)、残る課題、調査の記録(付録)の順に置く。

## 3. 足す規則

- 調査・分析の結びは、事実の再統合で終えず、根拠が支える範囲で次に何をすべきかを 1 段落書く。根拠がなければ再統合で止める。
- 調査の結びで提案を書くときは、「決める前にできる検証」と「決める場で選ぶ選択肢」に分ける。選択肢ごとに、支える数字・確かめること・選ぶ条件(「検証で〜なら A、〜なら B」)を添える。選択肢は、素材にある関係者の案・検証の結果で決まる案・何もしない案から作り、素材にない施策や数字(期間・費用・効果の見込み)は足さない。事実・解釈・打ち手を分け、どの文がどれに当たるかが分かるように書く。依頼に決めたいことがない定点観測では、選択肢を作らない。
- 定例・月次報告など続きの報告は、`../process.md` 5. の続きの文書の規則に従う。
- 強い数字の算式と前提は `../sentence.md` 4. に従う。

## 4. 外してよい規則

`../paragraph.md` 4. の「議論を支えない装飾的精度(時刻、HTTP ステータス、後で参照しない識別子)は省き、一般的な言い方で済ませる」は、付録の調査の記録には適用しない。再現に必要な日時・版・コマンドは省かずに書く。

## 5. 検査で見る点

- 結論の文のそれぞれに、対応する事実が項目ごとの結果にあるか。
- 出典を読み手がたどれるか(`../sentence.md` 8.)。
