# 技術記事

本ファイルは、技術記事(技術の題材を他者に説明する文書)の決まりを定める。技術書の章と解説文も本ファイルに従う。

## 1. 読み手

読み手は、分野の基礎は知っているが、題材は知らない他者である。

## 2. 節の並び

冒頭に導入の節を置き、対象・前提・扱う範囲を書く(`../paragraph.md` 3.)。続けて、問題や背景、解き方(例・コード)、結果と制約、次に読むものの順に置く。

## 3. 足す規則

- コード例は、そのまま実行して動く形で書き、対象のソフトウェアの版を書く。
- 術語は初出で説明する。`../sentence.md` 1. の「読み手が持たない語には初出で説明を添える」に従う。

## 4. 外してよい規則

`../paragraph.md` 4. の「議論を支えない装飾的精度(時刻、HTTP ステータス、後で参照しない識別子)は省き、一般的な言い方で済ませる」は、読み手が再現する出力・コマンドには適用しない。出力・コマンドは省かず、実行したとおりに書く。

## 5. 検査で見る点

- 例を実行し、本文に書いたとおりの出力になるか。
- スケルトン通読(`../paragraph.md` 5.)で、論旨が導入から結果へ一方向に進むか。
