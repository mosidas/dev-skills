# 調査ノート(notes)

判断に至るまでの調査・評価を記録する。1 調査 1 ファイルで、ファイル名は `<日付>-<スラグ>.md` とする。

- **ここに書くもの**: 現状の測定値、外部の設計指針との照合結果、採用・不採用の候補とその理由。
- **ここに書かないもの**: 確定した判断(`../decisions/` の `D-###` に置く)。現状の構造(`../DESIGN.md` が生成する)。
- ノートは判断の材料であり、後から覆ってよい。覆った場合もノートは書き換えず、覆した判断を `D-###` に記録する。
