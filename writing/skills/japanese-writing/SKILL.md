# 日本語ライティング規範

## 1. はじめに

- 本スキルは、日本語で開発ドキュメントや技術文書を書く・推敲するときの規範を、粒度別の層に分けて定める。本ファイルは工程(2.)・層の案内(3.)・優先規則(4.)を定め、規範の本文は `references/` の層別ファイルに置く。
- 作業に必要な層だけを読む。すべての層を常に読み込まない。

## 2. 工程

- 文書を一から構築するときは、次の順に進める。
  - 設計: 文書タイプが定まっていれば L5(該当 doctype)を読み、L4(構成)で情報を整理し、アウトラインとストーリーを決める。
  - 執筆: L1〜L3(表記・書式、文・語彙、段落・論証)を制約として、骨組みを本文に展開する。
  - 検査: `references/inspection.md` に従う。lint.py 等で機械検出し、構造・読みやすさは目視でレビューして、判断台帳で「直した / 残す(理由)」に仕分ける。
  - 収束: 台帳の仕分けが尽き、修正が新しい検出を生まなくなるまで、検査と修正を繰り返す。
- 既存文書の推敲・リライトでは、対象の粒度に応じた層だけを適用する。一文の修正に L4 は不要であり、構成の再編に L2 の点検は後段でよい。
- 「AI っぽいか」の診断だけを求められたら、書き換えずにスコアと理由を返す(`references/inspection.md` 9.)。

## 3. 層と参照ファイル

| 層 | ファイル | 扱う規範 | 読むとき |
| :-- | :-- | :-- | :-- |
| L1: 表記・書式 | `references/format.md` | 記述フォーマット(GFM)、見出しの付番と言葉、文書のメタ情報、表記、記号、図・表・式・コード、参照・引用(読み手がアクセスできる資料に限る)、RFC2119、表記の一貫性 | 本文を書く・直すとき |
| L2: 文・語彙 | `references/sentence.md` | 視点と語り、文の組み立て(語順・読点・一文一義・主語述語の近接)、語彙、リズムと鋳型、演出の抑制、事実・意見・確信度、禁止語(LLM 常套句)、翻訳調、冗長の排除 | 本文を書く・直すとき |
| L3: 段落・論証 | `references/paragraph.md` | 段落と論証、論証の厳密さ、接続詞、読み手の負荷の管理(読者の 3 軸・接地) | 本文を書く・直すとき |
| L4: 構成 | `references/composition.md` | 文書構築の工程、情報の整理と素材の収集、アウトライン(見出し・節の濃淡)、ストーリー(導入・結論先行・結び)、段落への展開、構築後の見直し(スケルトン通読) | 文書全体・章節を設計・点検するとき |
| L5: 文書タイプ | `references/doctypes/` | タイプ別の必須要素・構成の型・品質基準・やりがちな失敗と、L1〜L4 への例外・重み付けの宣言 | 文書タイプが定まっているとき(下表) |
| X1: 検査 | `references/inspection.md` | 検査スクリプト(lint.py・outline.py・terms.py)の使い方、lint カテゴリごとの対応方針、判断台帳、収束条件、手動チェックリスト、診断(score) | 書いた後に点検・推敲するとき、AI 臭さを診断するとき |

文書タイプが定まったら、対応する型を読む。

| 文書タイプ | ファイル |
| :-- | :-- |
| 仕様書・規約・アーキテクチャ指針 | `references/doctypes/spec.md` |
| 手順書・社内ガイド・マニュアル | `references/doctypes/procedure.md` |
| 調査・分析・評価レポート | `references/doctypes/report.md` |
| 議事録(文字起こしからの議事録化を含む) | `references/doctypes/minutes.md` |
| リサーチメモ・ディスカッションペーパー・企画書 | `references/doctypes/memo.md` |
| スライド構成 | `references/doctypes/slide.md` |
| 技術書の章・記事・解説文 | `references/doctypes/article.md` |

- 推敲・リライトの before / after 事例集は `references/examples.md` に置く。
- 検査スクリプトは `scripts/` にあり、`uv run` で実行する(依存はスクリプト内で宣言済み)。

## 4. 優先規則

規範どうしが競合するときは、次の 3 条で裁定する。

1. L1(表記・書式)は、文書種別を問わず適用する。文章品質の規範と書式が衝突する場合、書式を優先する。
2. 文書タイプによる例外は、`references/doctypes/` の各ファイルが「共通規範への例外と重み付け」の節で宣言した項目に限る。宣言のない項目は共通規範に従う。文書タイプによらず、引用・参考文献のタイトル等、原典の表記を保つべき箇所は、本規範に従わなくてよい。
3. 同一層内で規範どうしが衝突するときは、読み手の得になるほうを選ぶ。
- 層をまたいで扱いが重なる項目(段落のトピック、見出しの言葉など)は、粒度の細かい層の規定を正とする。
