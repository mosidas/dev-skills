# 調査・分析・評価レポートの型

## 1. この型が答える問い

調査レポートが答える問いは「何が起きていて、次に何をすべきか」である。データを集めて記述するだけでは完結しない。読み手が知りたいのは数字の羅列でなく、その数字が意思決定にどう関わるかであり、その翻訳を著者が代行しなければ、読み手は自分でグラフを睨んで解釈をやり直す。良いレポートは、冒頭の数行で「結局どうすればいいか」まで判断できる。

## 2. 必須要素

- 冒頭サマリー(結論と主要数値)。見出しは、文書が問いへの答えを導いている場合に「結論」とし、状況の集計・進捗のように議論を展開しない報告では「概要」とする。導出のない集計に「結論」の見出しを付けると、読み手は導出を探す。
- 目的とスコープ。目的として書くのは調査・作業の目的(何を明らかにするための調査か)であり、文書の執筆方針(何を省くか・誰に向けて書くか・どの資料を読まずに済ませるか)ではない。執筆方針と想定読者は本文に書かない。
- 前提・母集団の定義(「訪問数」がボットを含むのか、集計期間はいつまでか)。定義が調査のたびに揺れると、前回との比較が成立しない。
- 本題(調査結果)。
- 方法(第三者が再現できる手順)。
- データの限界。
- So What(次に何をすべきかの提案)。

方法とデータの限界は、分量が少なくても省略しない。方法がなければ数字の信頼性を検証できず、限界がなければ数字が独り歩きする。

必須要素の並びは見出しの文面ではない。「結論と主要数値」「方法と限界」のように要素をつないだ見出しを作らず、要素ごとに節を分ける(`format.md` 2.)。

## 3. 構成の型

- サマリーピラミッドで組み立てる。冒頭に結論と主要数値、本文に裏づけの詳細、技術的な詳細(集計クエリ・除外条件)は末尾か付録に回す。読み手は冒頭だけで意思決定でき、根拠を確認したい読み手だけが先へ進む。
- トップレベルの見出しは、報告書の構成要素で揃える(はじめに、調査結果の要旨、調査内容、調査結果、対応方針、課題事項など)。個々の調査事項は「調査結果」の下位へまとめ、章ではなく節で受ける(`format.md` 2. の見出しの粒度)。
- 調査の経過をたどる章立て(結論 → 経路 → 照合 → 個別の事象 → …)にしない。節は対象・事象などの分類で並べ、調べた順序は方法に書く。
- 続編の調査は、冒頭サマリーの直後に前回調査との関係を一段落で書く(何が変わって再調査したのか、前回の結論のどこを継承しどこを覆すのか)。前回調査との関係はこの一段落にとどめ、先行調査の主張を項目ごとに判定する節(主張ごとに「誤り」「再現不能」と判定する表)は設けない。数値が食い違うなら、本調査の測定値を示すにとどめる。
- 過去の誤りの訂正は、末尾でなく冒頭近くで明示する。信頼は結論を読む前の段階で確保する。訂正として明示するのは自分の報告の誤りであり、別の書き手による先行調査の判定には使わない。

## 4. 品質基準

- 冒頭サマリーだけで「結局どうすればいいか」まで分かる。
- 事実(「〜だった(出典: アクセス解析、7 月集計)」)と考察(「〜と考えられる」)が、地の文の中でも見分けられる。出典の一次・二次の別を明示し、自社の一次データと他社事例からの類推を混ぜない。
- 誤読しやすい数字(外れ値支配、母数の小ささ、季節性)は、読み手が気づく前に著者が指差す。注記は末尾に隔離せず、該当する数字のすぐそばに置く。
- 数字の意味が翻訳されている。「継続率は 4% だった」で終わらせず、「裏を返せば 96% が離脱している」まで書く。
- セグメントごとに濃淡がある。異常や示唆のあるセグメントは厚く、平常のセグメントは「特に変化なし」の一言で流す。

## 5. やりがちな失敗

- データの記述で力尽き、So What まで踏み込まない。「訪問数は前月比で減少した」で終わり、「だから何をすべきか」がどこにもない。
- セグメント別の記述を全部同じ文型で並べる(「A は〜だった。B は〜だった。C は〜だった。」)。重要な差分が見えなくなる。
- 注意書きを末尾にまとめて隔離し、冒頭の数字だけが独り歩きする。
- 母集団の定義を明記せず増減を語る。増減が集計方法の違いを比較しているだけの可能性を排除できない。
- 「今後の進め方」を、工程の順序をなぞるだけの自明な手順(「実装を続け、次へ進める」)で埋める。書くのは、読み手の判断や期待に関わる点(いつ利用者から見える形になるか、何が決まっていないか、何を確認する必要があるか)に限る。
- 作業の過程で作った中間ファイル(調査メモ・下書き)への参照を本文に残す。読み手はその文書を持たない(`format.md` 6.)。

## 6. 共通規範への例外と重み付け

- 例外: なし。共通規範をそのまま適用する。
- 重み付け: 結論先行と冒頭要約(`composition.md` 5.1)、結びの So What(`composition.md` 5.5)、事実・意見・確信度(`sentence.md` 6.)、接地(`paragraph.md` 4.)を特に強く適用する。

## 7. 雛形

```
# そらマルシェ 流入経路調査(2026年6月分)

訂正: 前号(5月分)で「検索流入は横ばい」と書いたが、集計対象に
社内アクセスが混入しておりデータの誤りだった。除外後は前月比
5%減で、今号の「2カ月連続の減少」はこの訂正後の数値と接続する。

## 結論
検索流入の伸びが鈍化した一方、SNS経由の購入率がサイト平均の
2.3倍まで上がっている。次回施策はSNS導線の強化を優先する。

## 主要数値
- 総訪問数: 128,400(前月比 -3%)
- SNS経由の購入率: 4.6%(サイト平均2.0%の2.3倍)
- 検索流入: 71,200(前月比 -8%、前々月から2カ月連続の減少)

## 注記(先に断っておく)
SNS経由の購入率のうち、上位1商品(季節限定の虫よけスプレー)が
購入全体の41%を占める。この商品を除くと購入率は2.1%まで下がる。
```

議論を展開しない状況報告では、「## 結論」を「## 概要」に置き換える(2.)。
